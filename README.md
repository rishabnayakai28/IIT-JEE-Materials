## 🤝 How to Contribute

We actively encourage contributions! If you have better quality notes, latest mock tests, missing solutions, or specialized materials that would help other JEE aspirants, please feel free to contribute them here. 

### Step-by-Step Guide to Pull Requests

**1. Fork the Repository**
Click the "Fork" button at the top right of this page to create a copy of this repository in your own GitHub account.

**2. Clone your Fork**
Clone the forked repository to your local machine:
```bash
git clone https://github.com/YOUR-USERNAME/IIT-JEE-Materials.git
cd IIT-JEE-Materials
```

**3. Create a Branch**
Create a new branch for your specific contribution. It's best practice to give it a descriptive name:
```bash
git checkout -b add-2025-mock-tests
```

**4. Add Your Materials**
Place your `.pdf` or `.docx` files in their respective subject or institute folders. If adding a new institute, create a well-named folder for it.
*(Reminder: Please ensure any file pushed is under 50 MB to prevent GitHub connection timeouts. If your file is larger, consider compressing it before tracking.)*

**5. Commit your Changes**
Stage and commit your modifications with a meaningful message:
```bash
git add .
git commit -m "Add latest 2025 mock test papers for Physics"
```

**6. Push and Open a PR**
Push your newly created branch up to your fork on GitHub:
```bash
git push origin add-2025-mock-tests
```
Finally, go back to the original `IIT-JEE-Materials` repository on GitHub. You will see a banner prompting you to "Compare & pull request". Click it, provide a brief description of what you've added, and hit **Create Pull Request**.
